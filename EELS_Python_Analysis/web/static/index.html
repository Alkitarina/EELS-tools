导入光谱数据

选择 MAT、HDF5 或 EELS-ZEST 结果 ZIP，开始分析。

EELS-ZEST 导入

直接读取 ZIP，无需手动解压。不重跑 ZEST，不裁掉负值，不按像素归一化。原能量轴不会应用逐像素能量修正；校正轴仅在所有有效谱线的公共范围内插值，不外推。

空间坐标从导出文件读取。旧 ZIP 若缺少 nm 标定，请在处理程序补全后重新导出；这里不假定像素尺寸。温度误差不用于峰位误差，温度图不作为总计数图。

导入流程 JSON

选择已导出的界面工作流（如 try 2-7）。恢复选区、实际运行参数和各区峰结果，然后继续调整。

JSON 不包含完整谱图。导入会用匹配的 H5 重建分解和体谱，保留已保存的峰位、宽度及振幅，不重新寻峰。H5 已移动时，可填写新路径，或先通过“导入数据”载入。

不同程序版本重建的谱图可能有差异；只有导入全部成功才替换当前工作流。可通过工作流的“取消”按钮停止导入。
