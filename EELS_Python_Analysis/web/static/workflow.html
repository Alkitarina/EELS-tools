框选初值 ROI，并预览平均谱

这些选框独立于第 3 步分析选区。可给部分或全部组分指定初值，未指定的组分使用 NNDSVDa；仅首个起点使用 ROI，后续谱形仍自由优化。组分会重新排序，初值编号不代表最终材料标签。

初值谱须非负；截零策略仅处理初值，另加最大强度的 10⁻⁸ 正值下限，避免 NMF 零通道无法更新。运行时从已应用的 ROI 重新提取初值。

组分谱与空间权重都约束非负。除首个起点外使用独立随机起点，保留重建误差最小者。NMF 的截断只影响分解副本，后续体谱和残差仍用原输入。

本次局部分析范围的谱组分

归一化权重 = (权重 − 最小值) / (最大值 − 最小值)，阈值不是成分含量或置信度。先选择有空间差异的组分，再核对候选区域及均谱。

阈值相对当前组分权重的最小值与最大值归一化；候选框采用所选连通区域的外接矩形，可继续手动调整。

结构像辅助对照（可选）

图像映射到当前 xy 范围；此功能不自动完成跨模态配准，需先在外部裁切 / 配准并核对方向。不会将总计数称为 HAADF。

保留每条带的 x–E 分布，建立两侧体谱

在总界面选框的 y 范围内分条带，每条覆盖完整 x 轴。

按界面位置配准（可选）

单个位置点表示直界面；多个点须覆盖本次条带的全部 y 像素行。沿完整 x 轴线性插值，只保留这些行共有的距离范围，不外推。原始区域框、分解和空间图保持不变。

条带实测数据独立生成。Si / Ge 选框仅提取整框平均体谱，不限制条带的 y 范围或完整 x 轴。
