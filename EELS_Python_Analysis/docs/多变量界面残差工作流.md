# NMF / MCR-ALS 界面残差工作流

在网页顶端选择 **NMF / MCR-ALS · 界面残差工作流**。PCA、高斯自动、高斯手动约束保持各自的参数区；切换方法不运行分析，不重置旧方法的选框、结果或误差。

参数现在自动保存到项目的 `web_runs/ui_preferences.json`，包括 ROI 初始化下拉选项、初值框与启用开关，重启服务也可恢复。计算结果仍需由运行中的服务提供或重新计算；详见 [参数记忆](参数记忆.md)。

本流程直接使用已降噪、已扣背景的 HDF5 `intensity[y,x,energy]`。它不再次执行降噪或背景扣除，也不把 PCA 重建谱作为默认体谱。此前暂停的 PCA 体谱扣除实现已归档至本地任务备份，未接入此流程。

## 1. 全像素分解

确认输入处理状态，并明确选择完全位于数据轴内、至少含 8 个通道的可靠能量窗。全体像素按 y、x 顺序展开为 `(Ny*Nx, NE)`；只有在此能量窗中含非有限值的像素被排除，其空间权重图保留空白。不会按 ROI 或随机抽取部分像素训练。

分解目标为 `X ≈ C @ S`，`C >= 0`、`S >= 0`，不约束每个像素的权重和为 1。

- **MCR-ALS**：交替求空间权重和谱组分的非负最小二乘；使用热启动批量坐标下降，检查 NNLS 的投影梯度。内部最多 500 轮、相对阈值 1e-7，未达阈值会记录警告。输入中的负值保留并进入误差目标。
- **NMF**：欧氏误差的乘法更新，需要非负输入。默认遇到显著负值停止。只有明确选择“仅分解副本的负值截为 0”才进行截断；128 倍浮点 epsilon 相对全窗幅度以内的负值按舍入误差处理，并仍报告实际截断数量。
- 首个起点可选 NNDSVDa、随机或 ROI 平均谱，后续起点使用独立随机初始化。`SeedSequence(seed).spawn(starts)` 固定各起点随机流；选择已尝试起点中误差最小者。达到最大迭代次数不等于收敛，页面和导出均保留状态。
- NNDSVDa 的初始估计使用输入的正部；MCR-ALS 随后的优化仍使用原有符号数据。
- 组分按谱重心升序排列，非零谱组分按统一能窗内的积分归一为 1，对应空间权重乘回相同因子。塌缩的零组分明确警告。权重单位是输入强度 × meV，不是原子分数。

组分数、能量窗、初值和约束都会影响 NMF / MCR-ALS；分解并不保证唯一，也不自动命名材料。各起点 RMSE、迭代数、收敛状态和所选起点均可查看。NMF 的优化 RMSE 可能对应截断副本；空间误差图及“相对原输入 RMSE”始终与原始已处理输入比较。

方法参考：[scikit-learn 分解说明](https://scikit-learn.org/stable/modules/decomposition.html)、[NIST pyMCR 说明](https://pages.nist.gov/pyMCR/)。本项目使用自身实现，没有新增 scikit-learn 或 pyMCR 依赖。

### ROI 平均谱初始化

第 1 步将“首个起点”切到 **ROI 平均谱初始化**。可在初值积分图 / 总计数图上拖动、调整各初值的选框，或输入坐标后明确应用。可从第 3 步的分析选区复制坐标；复制和编辑只影响初值选框，不改变原分析 ROI。底图切换和 Esc 取消保留现有初值与分析结果。

默认给初值 1、2 各提供一个可编辑 ROI；可取消或启用其他组分的 ROI。至少指定一个，最多等于组分数。未指定的组分使用 NNDSVDa 初值。每个 ROI 至少包含 2 个在完整统一能窗内均有限的像素，先求原始已处理谱的平均值。预览不执行分解；实际运行重新提取均谱。

由于分解组分要求非负，ROI 均谱遇到显著负通道时默认停止。可明确选择“仅初值截零，保留原数据”。初始化谱额外设置其最大值的 `1e-8` 正值下限，防止乘法 NMF 的零通道锁定，然后按 L2 范数缩放。预览同时显示原均谱和缩放前的非负初值。此策略独立于 NMF 的输入副本截断；MCR-ALS 优化和后续残差始终保留原输入负值。

这些谱只用于首个起点的 H0，后续 W/H 均自由更新。其余起点仍随机生成，误差最小者可能来自随机起点，结果会明确注明；初值编号也不等于按谱重心排序后的组分编号。几乎相同的初值谱会提示可能无法区分。导出记录实际 ROI、组分索引、负值策略、有效 / 排除像素、正值下限和所选起点，复现从原数据重新构造 H0；不在默认 JSON 内塞入均谱数组。

## 2. 组分、参考谱和分区

第二步同时显示组分谱与 xy 权重图。可导入仅作形状对照的参考谱 JSON：

```json
{"name": "Si reference", "energy_meV": [10, 11, 12], "intensity": [0.2, 0.3, 0.5]}
```

参考谱须包含等长、有限数组和递增能量。比较显示按绝对面积归一化，不将此曲线自动用作体谱模板或优化约束。

第三步可切换统一能窗积分、组分权重、分解重建误差、保留的 EELS 总计数。总计数不称为 HAADF。还可载入已在外部完成同视场裁切 / 配准的 PNG、JPEG、WebP 结构像，并在核对坐标范围和方向后叠加选框；支持显示翻转，不自动做跨模态配准。

四个框表示 Si bulk、Ge bulk、总界面和可选位错核附近；分析时的普通界面为“总界面框 − 位错核框”。支持边角调整、移动、框外重画、数值坐标和 Esc 取消。切换底图不改变任何框。分解仅提供证据，材料名称及位错位置由用户确认；可填写分区依据备注。

- Si 与 Ge 体区不能共用像素；界面、核区域不能与体区共用像素。
- 普通界面从自己的矩形中排除所有核区像素，避免重复平均。
- 已确认的手动调整使下游体谱 / 残差结果失效；Esc 和无变化点击保留结果。重新完成分解后，下游结果需要重建。
- 同一数据下切换分析方法保留独立工作区状态。成功导入新数据会清除旧结果、参考图像和预处理确认；可用数值参数与选框尽量保留。

### 第 3 步：总计数拟合总界面（可选）

展开“① 总计数 + erf / logistic 拟合总界面”。从保留的 EELS 总计数图沿 y 平均，拟合被展宽的阶跃；可切换 erf 与 logistic，并预览归一化计数曲线、拟合曲线及主图上的候选边界。总计数不等同于 HAADF，这仍是衬度候选边界，不能独立证明结构界面或互扩散宽度。

默认边界为 Si 平台 99%、总界面 10–90%、Ge 平台 99%，均可调整。点击“拟合并预览”不会改动任何现有选框。点击“应用拟合选框”才更新选区：默认仅应用总界面并保留两侧体区；也可选择同时应用 Si / 总界面 / Ge。应用时默认上下取满，可取消以保留各框的 y 范围。

应用前检查像素范围及区域重叠；失败时保留原选框。两侧 99% 边界超出视场时，只要总界面边界有效，仍可仅应用总界面。没有保留总计数时该拟合不可用，需手动设定范围。后端拟合最长 8 秒，前端等待最长 12 秒，支持取消并拒收过期响应。应用后仍可手动调整。

### 第 3 步：扩展界面邻域的局部分解与候选核预览（可选）

展开“② 界面邻域 NMF / MCR-ALS”。局部方法可独立切换，支持组分数、NNDSVDa / 随机初始化、起点数、种子、迭代上限与收敛阈值。默认以**当前已应用的总界面框**为基准，左右各扩展原宽度的 100%，总分析宽度为原来的 300%，y 范围保持不变。拟合后手调选框时，以手调后的范围为准。

设原界面为 `[xL, xR]`、宽度 `W = xR - xL`，默认分析范围为 `[xL - W, xR + W]`。例如原框 7.499–9.141 nm，对应局部分析 5.857–10.783 nm。可修改“x 两侧各扩展 (%)”，0 表示原范围，100 表示三倍总宽；该选项随参数记忆保存。接近图像边缘时只保留现有像素，并明确提示截边，不生成外推数据。实际像素数取决于采样网格，不要求恰好三倍。

局部分解使用**扩展范围内全部有限像素，包括已圈出的位错核**，并沿用全图分解的实际能量窗。它直接分解原始已处理输入，不分解全图组分的重建谱，也不先扣两侧体谱。扩展只改变局部分解与候选搜索范围，**不修改 Si / Ge / 总界面 / 位错核四个分析框**。主分区图青色虚框表示待分析范围；局部权重图的橙色虚框保留原总界面参照。

局部 MCR-ALS 保留输入负值，约束谱组分和空间权重非负；局部 NMF 遇到负值默认报错，只有显式选择后才对分解副本截零。两种方法的组分都只是定位线索，需结合结构像、参考谱和空间分布核对。

完成后可选择一个局部组分，查看它的谱形和 xy 权重图，再生成候选核：

1. 权重按该组分在实际局部分析范围内的最小值、最大值归一化：`Wn = (W − min(W)) / (max(W) − min(W))`。
2. 选择高于或低于百分比阈值的像素；这不是成分含量、百分位数或置信度。
3. 按 8 邻接查找连通区域，过滤小于“最小连通像素数”的区域，并按像素数从大到小列出最多 50 个候选。最小值可设为 1。
4. 预览候选像素及其外接矩形，并显示矩形额外包含的像素数。候选可以横向偏出原界面框。谱图比较的是**矩形内的原始已处理均谱**与原总界面框扣除该矩形后的均谱；新增的两侧范围不会混入“其余总界面”均谱。
5. 核对后点击“应用候选核选框”，启用 Core 并更新矩形；可继续手动调整。普通界面随后排除 Core 框内像素。

平坦权重图、无候选区、与体区重叠或覆盖全部普通界面的矩形不会被自动采用。局部分解和候选预览均不改变现有选框、体谱或分峰；只有应用了改变的选框才使下游结果失效。总界面框或扩展比例改变后，旧局部结果仍显示其实际计算范围；必须重新分解才能生成或应用新候选。

局部计算使用与主流程相同的独立隐藏进程、时间限制与取消机制。局部任务成功、失败、取消、超时都保留已有主流程分析结果。重新完成全图分解则使局部结果失效。

## 3. 界面配准、y 条带、体谱模板

只在**总界面选框的 y 范围**内按指定的像素行数分条带，从框内第一行原始像素开始，保留每条带的**完整 x 轴**及 x–E 均谱。总界面框的左右边界不裁切条带；位错核从普通界面中排除时也不会删掉相应条带行。末条带可少于指定行数，行数和范围均会记录。**Si / Ge 框的 x、y 范围均不限制条带实测数据，也不要求 bulk 框与条带相交。**

例如总界面只包含原始第 4–11 行，条带高度为 3 行，则生成第 4–6、7–9、10–11 行三个条带；每个条带都从扫描图最左端延伸到最右端。界面框之外的 y 行不生成条带。

可选配准输入为每行 `y_nm, x0_nm`：一个点表示直界面；多个点须按 y 唯一并覆盖本次条带选中的全部 y 像素行。先线性插值得到 `x0(y)`，再逐行按 `d = x - x0(y)` 沿完整原始 x 轴线性重采样，网格间距取原 x 步长中位数，只使用这些行共有的距离范围，禁止外推。因此配准后的 d 轴可能比完整原始 x 轴短。此配准不改原始 ROI，也不改变已完成的分解。配准后的像素具有插值相关性。

Si 和 Ge 各从自己的**整个 ROI**提取一个原始已处理平均谱，供后续体谱分峰和扣谱参考。所有条带共用这两个参考谱，不再把 bulk 框与每条带的 y 范围取交集。例如 Ge 框只到 y＝12.74 nm，而总界面到 19.58 nm，后面的条带仍完整生成。共用谱并不表示把 bulk 框纵向扩展到全图，其平均像素始终来自你实际选定的框。

条带实测图先独立生成，再尝试参考体谱和扣谱。参考模板需要每侧至少 2 个完整有限像素；均谱不足或参数化拟合失败时，仅对应扣谱不可用，实测 x–E 图仍可选、可看、可导出。列表分别报告实测条带数和可扣谱条带数，不再用笼统的“缺失”表示模板失败。只有原始条带确实没有有限谱线时，才提示无有效实测谱。

第四步与第五步的条带列表中，只要该条带与已启用位错核的 y 范围共享至少 1 行原始像素，就显示为紫色并标注“涉及位错核”；**不检查核区的 x 位置**，所以核区横向偏出总界面框也会被标记。判断使用建立体谱时保存的 Core ROI 和完整 y 像素中心坐标，包含边界行，不以缩略图或仅连续坐标相交替代；提示记录重叠的行数。这只是条带显示标记，普通界面与核区的实际谱仍按各自二维选框和排除规则计算。

体谱可直接用均谱，或可选 Gaussian / Lorentzian 参数化模板。后者先检测可分辨峰，再进行有边界的线型拟合；不额外引入背景。模板拟合失败会说明原因，并保留实测条带；有效的 Si / Ge 均谱仍可在第五步独立做高斯分峰。界面图可查看均谱与实际模板的差异，模板参数、像素数和 RMSE 都会保存。

**指定区域、逐 x 和条带范围目标共用整框提取的 Si / Ge 参考体谱。** 待分析的条带实测谱依然分别保留，并未沿全部 y 合成一个谱。过去“每条带与 bulk 框相交”的选项仅为旧端口和历史配方保留，新版页面不再使用，参数记忆也不会将它带回。

## 4. 非负体谱贡献与有符号残差

对每个条带的每个 x，或选定区域 / 条带 x 范围的实测均谱，求解：

`min_(a,b >= 0) ||Y(E) - a*Si(E) - b*Ge(E)||²`。

使用两个基谱的精确 NNLS：比较内部无约束解、两条坐标轴边界及原点。谱线不平移、不归一化、不追加常数项，权重不要求和为 1。列范数归一仅为求解数值稳定性，结果会换回原模板尺度。模板近乎共线（归一化条件数 > 1e8）时拒绝分别估计两个权重。

`R(E) = Y(E) - a*Si(E) - b*Ge(E)` 保留全部正负值；NMF 曾使用的截断副本不会进入这一步。

页面显示实测谱、Si / Ge 各自贡献、贡献和、残差以及条带 x–E 图。诊断包括残差 RMSE、正负积分、负残差通道比例、残差与两侧体谱一阶导数的相关性。明显导数相关提示先检查能量漂移、体谱峰位变化或模板不匹配；这些诊断不会自动校正数据。

## 5. 体区高斯分峰、残差峰与联合拟合

第五步按“分析对象”分别保存参数与结果：

- **Si / Ge 体区**：直接对该 ROI 的原始已处理平均谱做正振幅高斯分峰，不先扣除 Si/Ge 体谱。可调整峰数、突出度、峰距、峰位搜索范围和 FWHM，也可手动输入峰位。预览显示原均谱、总拟合和各高斯子峰；记录峰位、FWHM、振幅、面积、收敛与边界状态。这里的分峰是独立的体谱表征，不自动替换第四步建立的扣谱模板。
- **普通界面 / 位错核附近**：先扣除两侧体谱，再进行下面的有符号残差分峰和联合拟合检查。
- **条带范围**：保留原有局部残差分析，另存最后一次条带结果。

切换对象保留各区已完成结果和编辑参数；导出使用实际运行参数。可以分别拟合，也可使用“按各区参数拟合全部区域”。批量任务覆盖已启用的 Si、Ge、普通界面和位错核；整体成功后才替换这组结果，取消、超时或任何区域出错都保留原结果。未启用位错核时不会生成它的拟合。重新完成分解 / 体谱建立或改变相关分析选区会使依赖结果失效。

网页默认在有符号残差上检测 **正峰和负峰**；可切换仅正峰、仅负峰。分别对 R 和 -R 找局部峰，并要求极值具有对应符号；合并后按突出度取最多指定总数，统一应用最小峰距。不会为纯舍入误差或无峰区域强制生成子峰。可手动给出候选峰位；正负模式按峰位处的残差判断方向，接近零时要求调整峰位或明确选单一方向。Gaussian / Lorentzian 的峰位搜索范围、FWHM 上下限可调。

两套模型使用相同候选峰与参数边界：

1. 固定上一步体谱权重，在残差上拟合所选方向的峰；负峰具有负振幅和负面积。
2. 在实测谱上联合拟合 `a*Si + b*Ge + Σ sign_j * amplitude_j * peak_j`；`a,b,amplitude_j >= 0`，`sign_j` 取 +1 或 -1，并与两步法保持一致。

非线性优化只搜索峰位和 FWHM；每个试探点通过包含有符号峰基谱的 NNLS 重求峰幅度及非负体谱系数。这样约束的是体谱权重和峰幅度绝对值，不约束残差非负。标准使用两个不同初始宽度；联合拟合还以两步法的峰参数为起点。峰位按顺序限制交叉。表格比较方向、峰位差、宽度、有符号振幅 / 面积、振幅比及 SSE；接近参数边界、基谱病态、明显峰位变化或未收敛都会提示。

负峰描述相对体谱模板的谱权重减弱，也可能来自峰位变化、展宽或模板不匹配，不能单凭负峰认定某个振动成分消失。峰的符号作为 `peak_signs` 保存，实际检测方向作为 `settings.polarity` 保存。旧 JSON 缺少 polarity 时仍按历史的仅正峰规则复现。

此步骤是同一数据的模型敏感性检查，不能替代独立结构证据。增加峰参数通常降低 SSE，不能单据此确认独立界面振动模式。应检查多个条带、不同体区 / 可靠能窗和模板选择下是否一致。

**目前此新流程不计算峰位 / FWHM 误差条，导出为 `uncertainty: null`。** 旧 PCA / 高斯方法的 bootstrap 功能保持原口径。

## 计算与导出

每步计算使用独立隐藏子进程和单线程 BLAS；页面异步轮询进度，可取消，默认 180 秒，可选 5–900 秒。取消、超时、数值错误和过期数据结果不会覆盖上一次完成结果。进程终止并等待退出后才清理对应的任务临时目录。

默认导出单个 UTF-8 JSON，文件名跟随导入文件主名。格式为 **`eels_interface_workflow_v1`**，与旧峰参数 JSON 分开；保存已完成步骤、实际设置、ROI、配准点、体谱元数据、权重、诊断及候选峰比较，不嵌入全谱 / 空间数组。旧 `eels_plot_workflow` 的 PCA 绘图与重算脚本不消费该新格式。

JSON 的 `results.regions` 固定列出 `Si`、`Ge`、`Interface`、`Core`。每项包含 ROI、预期分析类型、状态与对应结果；未拟合为 `not_analyzed`，未启用为 `disabled`，未检出峰为 `no_peaks`，未收敛为 `not_converged`，有效完成为 `completed`。缺失结果为 null，不填零参数。

Si / Ge 的 `result.analysis_kind` 为 `bulk_gaussian`，高斯峰参数放在 `result.bulk_fit`。界面 / 核区为 `residual`，分别保存 `two_stage`（残差谱分峰）和 `joint`（联合拟合），以及体谱权重和比较诊断。当前显示哪个区域不影响其他已完成区域的导出。`results.fit` 兼容保留当前选中的已完成结果，未指定时为最近完成结果；额外条带结果在 `results.strip_fit`。

复现配方先记录 decomposition、profiles，再逐区域记录多个 fit 步骤，每步保存独立 result_id、target_key、profiles_id、analysis_kind 与实际参数。允许最多四区加一个条带，不允许重复区域或错配父结果。旧的单项 fit 配方仍可读取；缺少 analysis_kind 的旧配方保留原残差分析行为，不把旧体区自检改标为高斯分峰。

局部探索作为独立分支保存：`results.localization` 包含当前已完成局部结果的 ROI 与摘要，`reproducibility.localization` 保存实际局部参数和对应全图分解 ID，复现时单独重算。原主流程步骤顺序不变。已应用的衬度拟合和候选核依据保存在建立体谱时的 `settings.evidence.partition_assistance`，包括边界、候选阈值、外接矩形及是否后续手动调整；之后试跑另一种局部分解不会改标此前核区的实际来源。导出不包含未执行的控件值或完整谱图。

扩展结果同时记录原 `roi`、每侧 `x_expansion_percent`、请求范围 `requested_analysis_roi`、截边后的 `analysis_roi` 和 `range_rule: interface_x_expansion_v1`。JSON 与 NPZ 均对应实际分析范围。旧配方缺少扩展参数时，数值复现仍只使用原界面框；不会把历史结果改标为三倍范围。

“导出谱图数组 NPZ”是显式可选操作，保存：`component_spectra_ke`、`component_weights_yxk`、`reconstruction_rmse_yx`、坐标和能量轴；有条带结果时还保存每条带的 `measured[x,E]`、`weights[x,2]`、`bulk_sum[x,E]`、`residual[x,E]`、`templates[2,E]`、`pixel_counts[x]`。数组保留全计算分辨率；网页大图仅为显示而降采样。

新配方的 `strip_data_rule` 为 `independent_full_x_v1`，条带 `measured_status` 表示实测数据是否可用，`status` 表示是否能扣谱。若只有实测数据可用，NPZ 仍保存 `measured` 和 `pixel_counts`，不伪造其余数组。历史配方缺少该规则字段时，重放仍沿用旧的耦合行为，不能用新版设置重新标注旧结果。

有局部分解时，NPZ 还包含 `interface_component_spectra_ke`、`interface_component_weights_yxk`、`interface_reconstruction_rmse_yx`、`interface_x_nm`、`interface_y_nm`；能量轴与全图相同。

条带结果同时记录实际 `settings.stripe_y_scope`：新版 UI/API 使用 `interface_roi`；历史 JSON 缺少此字段时仍按 `full_y` 的全图分段规则复现，不改换原条带编号。JSON 的 `results.profiles.strip_domain` 和 `strips` 保存实际范围、每条的原始行索引 / y 边界和 `core_overlap_rows`。NPZ 对应增加 `strip_row_bounds`（从 0 开始的原图半开区间 `[start, stop)`）、`strip_y_bounds_nm`、`strip_core_overlap_rows`，与条带索引一一对应，包含不可用条带的范围信息。

复现需要保留原 HDF5 和对应程序版本：

```powershell

.\.venv\Scripts\python.exe -X utf8 reproduce_workflow.py '结果.json' --data '移动后的数据.h5'
```

数据数值校验不匹配时拒绝执行。源码 / 环境不匹配需显式 `--allow-version-mismatch`，不承诺此时数值完全一致。输出另存 `_reproduced.json`，不会覆盖已有文件。默认 JSON 不包含原始数据副本。

## 截断能窗与峰高约束

所有扣体谱、残差和 Gaussian 拟合误差仅使用已完成全局分解的能窗内实际通道。候选峰和优化后的峰中心保持在窗内；高斯宽度/尾部允许跨越能窗边界，不补零、不对窗外生成观测或误差项。`areas` 仍为完整线型的解析面积，SSE/RMSE 只统计窗内通道。

步骤 5 新增“限制高斯峰高”开关和上限百分数，新 UI 默认为 150%。对每个初始候选峰，以其 `center_radius` 为邻域半径，与实际能窗取交集；正峰取实测信号局部最大值，负峰取负谷绝对值。上限在优化前固定为该值的指定倍数，不平滑、不移动基线，也不外推边缘。Si/Ge 使用原始已处理 ROI 均谱；Interface/Core 使用独立 NNLS 体谱扣除后的有符号残差。联合拟合与非联合拟合使用同一上限，避免联合体谱系数变化导致上限同步膨胀。

通过带上下界的线性最小二乘约束每个子峰的绝对振幅；体谱权重仍非负且无和为一约束。JSON 记录 `amplitude_limit` 设置及每个模型的 `amplitude_constraint`（参考能窗、初始候选峰、邻域、实测极值、实际绝对上限）、`at_amplitude_limit`；触顶同时计入 `at_constraint_boundary`。UI 显示真实已完成参数和各峰触顶状态。旧配方缺失该参数或显式为 null 时保留原来的无上限 NNLS 算法；不要默默给历史重放增加约束。

此限制抑制过强的正负子峰相消，不保证分峰唯一，也不代替物理验证。图上实际波形使用深色粗线，总拟合使用较细虚线，子峰使用淡色细线；不为改善视觉效果平滑实际数据。测试见 `tests/test_amplitude_limits.py`。

## 有符号残差的零线约束选峰

新 UI 的 Interface/Core 与条带残差拟合显式记录 `candidate_score: zero_baseline_prominence_v1`。自动候选评分为 `min(原突出度, 相对零线的绝对峰高)`，同时用于阈值筛选和降序取峰；阈值仍为最小突出度比例乘窗内残差的峰峰值。最小峰距、最大峰数、线型及峰高上限保持各自原有作用。零线附近浅谷不能借用两侧正峰的高度取得高评分，反号情况对称处理。

不平滑或裁剪实测有符号残差，不改变原始 `prominence` 的含义；候选记录额外保存 `selection_score` 和 `score_rule`。Si/Ge 独立体谱分峰不变。手动峰位不参与自动候选筛选。旧配方缺少该字段、为 null 或为 `prominence_v1` 时仍使用原突出度排序；未知规则报错。UI 分别说明下次拟合规则与已完成结果实际使用的规则，旧结果不会被重新标注。健康接口通过 `candidate_score_version` 声明支持。测试见 `tests/test_candidate_score.py` 与 `tests/browser_bulk_regions.cjs`。
