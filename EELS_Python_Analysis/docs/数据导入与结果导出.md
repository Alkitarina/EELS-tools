# 数据导入与结果导出

## 1. 启动与导入

日常在项目目录的 PowerShell 中运行，不再使用 BAT：

```powershell
.\start_web.ps1
```

程序会后台启动 Python，检查服务就绪后自动打开浏览器。默认地址为 `http://127.0.0.1:8768`，
最新版入口固定为 `http://127.0.0.1:8768`，被占用时不会自动顺延。相同代码的现有服务会复用；旧版需先导出结果再停止并在 8768 重启。终端可以关闭，服务会继续运行。
停止前先导出结果，再运行 `./stop_web.ps1 -Port 实际端口`。日志位于 `web_runs/`。
只启动不打开浏览器可以使用 `./start_web.ps1 -NoBrowser`。

已有兼容会话时优先复用并保留当前数据。新建服务默认打开空白 UI，不读取上次数据路径或旧默认 H5，也不弹出选文件窗口。
进入网页后用“导入数据”选择 MAT/H5，或用“导入流程 JSON”恢复已有流程。`-NoBrowser` / 非交互启动也无需文件。
仅显式使用 `-DataFile` 时启动才加载指定 H5。`last_launch.json` 只保留可选启动历史，不用于自动选取文件。
未导入数据时不会保存空白草稿或覆盖原参数记忆；导入成功后恢复适用设置。

点击右上角 **导入数据**，任选一种方式：

1. 选择本机文件。
2. 填写文件的本地绝对路径，适合较大文件，避免浏览器再复制上传。

支持 `.mat`、`.h5`、`.hdf5`。上传大小上限为 1 GB，更大文件用本地路径方式。

### Toolbox MAT 文件

当前适配的是 3D-EELS TOOLBOX 保存的、变量 `data` 为 `EELS` 对象的 MAT 文件，包括本次提供的 `2-14 result5.mat` 样例。

MAT 文件不只是普通矩阵，还含有 MATLAB 类对象。程序会后台启动本机 MATLAB，加上 EELS 类路径，再调用项目内的 `matlab/export_eels_to_hdf5.m` 导出数值。

转换内容为：

- `intensity[y, x, energy]`：强度三维数组，原数值不变。
- `x_nm`、`y_nm`：用像素尺寸生成的位置坐标，以第一个像素中心为零。
- `energy_meV`：保留原对象的能量轴，包括可能存在的负能量。
- `reference_maps/total_counts`：保留源对象的 `info.totint`，用于总计数参考底图；同时保存来源、空间轴序和可用状态。详细规则见 [H5数据格式与总计数](H5数据格式与总计数.md)。

**这里的转换只是格式转换，不会重新对齐、归一化、扣背景或解卷积。** 输入若已经解卷积，导入的仍是那份解卷积结果。请只导入可信来源的 MATLAB 对象文件。

MATLAB 首次启动可能需要等待。转换副本位于项目 `imports/唯一编号/` 下，原文件和 toolbox 源码保持不变。导入成功后清空旧数据的谱线预览、PCA 缓存、拟合及不确定度结果；导入失败则保留当前数据和结果。

在同一网页中导入下一份数据，默认沿用当前设置，包括能量范围、分析模式、峰数、峰位和峰宽约束、PCA 参数、重采样次数、块大小、并行任务数及可用空间选区。例如已设为 **10–80 meV**，换文件后仍为 **10–80 meV**，不会重新设为 0–120 meV，也不会根据新文件的 ZLP 覆盖峰宽下限。

如果新文件只覆盖部分能量范围，输入值不变，实际使用交集内的能量通道并给出提示；不足 8 个通道时暂停显示信号图并提示手动调整，不会自动扩大拟合窗口。空间选框按原来的 nm 坐标沿用，越界部分会裁剪；某个坐标方向没有选中像素时，该方向恢复到新数据的默认选区（默认也不包含像素时使用该方向全范围），并提示确认。请仍检查 Si、界面、Ge 的实际位置，程序不会自动识别材料。

上述沿用行为针对当前网页内连续导入，刷新或重新打开网页仍使用初始默认设置。切换数据或刷新前，请先导出需要保留的分析结果。

### MATLAB 找不到时

HDF5 导入不需要 MATLAB。MAT 导入需要 MATLAB 许可及 EELS 类。默认按本机安装目录和当前项目目录定位；更换电脑后可在启动服务的 PowerShell 中设置：

```powershell
$env:EELS_MATLAB_PATH = 'C:\Program Files\MATLAB\R2025a\bin\matlab.exe'
$env:EELS_TOOLBOX_PATH = 'C:\你的项目目录\calculation_program\3D-EELS TOOLBOX'
.\start_web.ps1
```

也可以独立转换，不启动网页：

```powershell
.\.venv\Scripts\python.exe import_eels_data.py 'C:\数据\result.mat' 'C:\数据\result.h5'
```

输出文件已存在时会拒绝覆盖。若 MAT 文件没有名为 `data` 的 EELS 对象，先在 MATLAB 中加载正确对象，再用原有 `export_eels_to_hdf5(对象, 输出路径)` 导出。

## 2. 导出之前

分别确认 Si、界面、Ge 的选区并运行分析。要得到不确定度，还需运行 **评估当前不确定度** 或 **评估全部不确定度**。未计算不确定度也能导出，但相关值为 `null`，状态为 `not_computed`，不会填写零。

不同区域可以有不同能量范围、峰数和其他参数。导出记录的是每个结果真正计算时使用的设置。之后只修改输入框而没有重新运行，不会改变旧结果的参数记录。

点击 **导出结果（JSON）** 后，下载文件默认与当前导入文件同名，仅将扩展名改为 `.json`。例如 `2-15 result5.mat` 导出为 `2-15 result5.json`，中文、空格和文件名中的其他小数点均保留；导入另一份数据后，默认名称随之更新。位置及已有同名文件的处理由浏览器下载设置决定，通常进入“下载”文件夹。它包含当前页面仍保留的 PCA 与高斯结果，每个模式每个区域保留最近一次。清空、切换数据、更新能量信号图和重新选框前，应先导出需要保留的结果。

## 3. 单个 JSON 保存什么

JSON 可以同时保存结果表和各区域不同的参数，不需要把复杂设置塞进 CSV 的额外行。它是普通 UTF-8 文本，可以直接查看，也能用 Python 的 `json.load` 读取。

| 字段 | 用途 |
| --- | --- |
| `format` | 格式版本，当前为 `eels_peak_results_v1` |
| `exported_utc`、`units` | 导出时间和单位 |
| `results` | 各区域分析结果，包括峰参数、误差和检出情况 |
| `results[].peaks` | 峰位、宽度、标准差、95% 区间、突出度或幅度/面积 |
| `results[].uncertainty` | 不确定度计算状态、成功和失败次数 |
| `reproducibility.data` | 输入数据路径、尺寸和数值校验值 |
| `reproducibility.software` | 算法标识、相关源码指纹、Python 与依赖版本 |
| `reproducibility.analyses` | 每个结果实际使用的选区、能量范围、约束和随机种子 |

`reproducibility` 固定写在文件末尾。它的 `analyses` 与前面的 `results` 通过 `result_id` 一一对应，不要靠数组下标猜哪个参数属于哪个区域。未检出峰时仍保留区域记录，`peaks` 是空数组。

为了精简，不再保存数据副本、整条谱线、逐次抽样结果或源码。固定输入数据、算法环境、完整参数和 seed 后，抽样可以重算；seed 本身不能恢复原始数据。

峰宽的 `width_kind` 有两种：`half_prominence` 是 PCA 半突出度宽度；`gaussian_fwhm` 是高斯半高全宽，两者不能不加区分地比较。

`center_std_meV` 和 `width_std_meV` 是成功自助样本的标准差（分母使用 N−1）；95% 区间使用 2.5% 和 97.5% 百分位，区间不必关于原估计值对称。失败重复不会当成零参与计算，重复失败较多时应谨慎解释区间。

## 4. 复现

保留对应的输入数据和程序版本，在项目目录中运行：

```powershell
.\.venv\Scripts\python.exe reproduce.py 'C:\results\eels_results.json'
```

脚本查找保存的输入路径，核验数据数值与版本，然后按每个区域保存的参数重跑 PCA/高斯及自助重复，生成 `eels_results_reproduced.json`。输出仍是同一 JSON 格式；不会覆盖已有文件，可用 `--output 新文件.json` 指定新位置。计算次数多时耗时与原分析相近。

数据改名或移动后，指定新路径即可，校验值不依赖文件名和 HDF5 压缩方式：

```powershell
.\.venv\Scripts\python.exe reproduce.py 'C:\results\eels_results.json' --data 'D:\数据\renamed.h5'
```

`--data` 也接受可信 toolbox MAT，此时需 MATLAB 先进行格式转换。只用 HDF5 复现则不需要 MATLAB。若输入数值发生改变，程序会拒绝继续，即使文件名相同。

若程序或依赖版本不一致，默认拒绝运行。先恢复记录的版本；确实要跨版本比较时，可加 `--allow-version-mismatch`，但这不保证完全一致，也不能跳过数据校验。旧 ZIP 文件仍可使用其自带的 `source/reproduce.py`，无需修改旧文件。

需要保留完整输入谱像：PCA 在整张谱像上学习主成分，空间自助法还要重新抽取像素，只保留三条平均谱不足以复现。但这份输入不需要再复制到每一个导出结果文件中。

复现范围从导入的数值数据开始，不包括之前的采集和 MATLAB 预处理。建议另外保存实验条件、能量校准与解卷积记录。JSON 只记录源码指纹而不保存源码本身；仍需保留对应版本程序。不同操作系统、CPU 数值库或 SVD 实现可能产生浮点偏差，不能承诺跨平台逐位一致。

文件包含数据路径、分析参数和结果。发给他人前，请确认这些信息适合分享。开发用的完整 JSON 结构和兼容规则已写入项目根目录的 `AGENTS.md`。
