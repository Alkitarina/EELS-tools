# 参考底图与候选界面

在左侧信号图上方使用 **参考底图** 下拉菜单。选择只改变左侧底图；Si／界面／Ge 三个选框、当前区域、分析参数、平均谱预览和已完成结果均保持不变。

| 选项 | 显示内容 | 来源 |
| --- | --- | --- |
| 当前能窗积分图 | 原来的 Parula 积分图 | 使用下面的分析能量范围 |
| EELS 总计数（非 HAADF） | 灰度总计数衬度 | 原 MAT 保存的 `EELS.info.totint` |
| 27–32 meV 参考图 | 固定窄能窗积分图 | 当前谱像 27–32 meV 通道，不改分析能窗 |
| Si/Ge 参考谱贡献图 | 从蓝到白到红的两侧参考谱贡献 | 当前谱像的左侧、右侧候选体区 |

“候选中心”复选框控制叠加虚线的显示。上方会列出 **总计数中心** 和 **光谱中心** 的近似 x 坐标。虚线不是选框，不会吸附、移动或重建任何选框。可以在任一底图上继续使用原来的矩形移动、边角调整和重新选区操作。

候选线是对整张图沿 y 平均后得到的过渡中点，当前显示为竖直线。它尚未独立验证为结构界面；对于倾斜、弯曲或位错附近的界面，需要局部检查。拟合不可靠或没有可辨认衬度时显示“未确定”，不画任意中心线。数字保留一位小数用于参考，不表示已达到 0.1 nm 的结构定位精度。

## 数据来源与缺失提示

新导入 MAT 时，程序会读取空间尺寸匹配的 `info.totint`，保存在转换文件的 `/reference_maps/total_counts` 中；不会修改原 MAT。

新 H5 明确记录总计数格式、来源、存储轴序和可用状态；MATLAB 与 Python 写入的轴序分别处理。完整规则及多变量文件的导入方式见 [H5数据格式与总计数](H5数据格式与总计数.md)。

旧 HDF5 可能只有谱像和坐标，没有保存总计数图。此时选择总计数会提示 **导入对应 MAT**，并保留原底图与选框。不能从已扣背景的声子谱直接恢复原来的总计数或 HAADF，因此程序不会用其他积分图冒充。

固定 27–32 meV 图和参考谱图也会检查能量覆盖和有效通道；数据不足时说明原因，不改变你的分析能窗。导入一个新数据集仍按既有规则使旧分析失效，并检查选框是否超出新数据范围；这与单纯切换底图不同。

## 光谱贡献与候选中心的定义

- 当 x 方向至少 20 列时，取第 3–8 列和倒数第 8–3 列的全 y 平均谱为两个参考。8–19 列时取左右四分之一宽的条带，至少各两列；少于 8 列时不建立光谱参考。
- 参考位置固定在图像两侧，与用户的 Si／界面／Ge 选框无关。左右两侧分别命名为 Si/Ge 的前提仍需由样品背景确认，算法不会鉴定元素。
- 使用 15–45 和 55–75 meV 两个能窗做非负双参考谱拟合，排除 45–55 meV。固定窗口只用于显示参考图，不影响 PCA、高斯拟合或能量输入。
- 两参考谱按定位能窗内总和归一化，显示 `b/(a+b)`；该量是光谱贡献，不是 Ge 原子分数。
- 总计数图和贡献图各自沿 y 求平均，用两端参考条带均值归一化，再拟合带上下平台的误差函数。x0 是拟合曲线的中点；两条线不一致时应检查原因，不自动取平均。
- 图像显示维持相同坐标、方向和物理比例，候选线与区域框共用坐标映射。

候选中心及参考底图是显示辅助，不改变峰分析算法，也不新增到峰结果 JSON 的实际分析参数中。空间 ROI 仍按用户实际选择的坐标导出。

## 启动和验证

首次运行 `./start_web.ps1 -DataFile 'C:\data\sample.h5'`，提供自己的 H5；已有兼容会话时可省略数据参数。启动器要求服务支持 `reference_maps_v1`；遇到旧版或不兼容服务会使用后续端口，保留原服务及其结果。

后端测试：`./.venv/Scripts/python.exe -X utf8 -m unittest discover -s tests -v`。

浏览器回归：`node tests/browser_reference_maps.cjs`，使用 Playwright 与本地 Chrome，在独立临时服务中检查连续切换、失败回退、慢响应、选框/结果保留和窄屏布局。
