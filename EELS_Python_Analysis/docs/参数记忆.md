# 重启后保留参数

新版网页自动将参数保存到本项目的 `web_runs/ui_preferences.json`。它不在系统临时目录里；刷新网页、关闭再启动服务，或在本项目的新端口打开，都可以恢复。页面顶端会显示保存状态，也可以点击“保存参数”立即保存。

保存内容包括：

- 当前分析方法，以及 PCA / 高斯模式的数值、下拉选项和开关。
- 全图和局部 NMF / MCR-ALS 的方法、初始化、随机种子、能窗、迭代和超时设置。
- ROI 平均谱初始化选项、八个初值框及各自是否启用，降低组分数不会删除暂时隐藏的初值框。
- 四类分析选框、是否启用位错核、总计数 erf / logistic 选区参数。
- 条带与体谱选项，以及 Si、Ge、普通界面、位错核各自的分峰参数草稿。

同一文件路径、数据尺寸与坐标范围匹配时恢复选框和预处理确认。换了文件则恢复通用参数，选框和预处理确认采用当前数据的设置，避免把另一份数据的几何位置直接套过来。网页内连续导入仍沿用原有的参数保留与选框范围检查规则。

这是**参数记忆**。计算结果、谱图数组、上传的结构图和参考谱文件不存入参数文件；结构图配准确认也不会自动恢复。服务仍在运行时会先恢复其已有工作流结果，再恢复你最后编辑的参数。即使参数已改但尚未重算，导出 JSON 仍记录原结果实际使用的参数。重启服务后需要重新计算结果；恢复参数不会自动启动分析。

多个页面共用一份最近设置，以最后保存的页面为准。保存请求超时或失败会提示，已有分析仍可继续；可以点击“保存参数”重试。若读取失败，则保留原参数文件并提示刷新重试，不用默认值覆盖它。

运行 `start_web.ps1` 打开支持参数记忆的新端口；旧服务的计算结果保留在旧端口。删除 `web_runs/ui_preferences.json` 会失去这份参数记忆，请勿将它作为临时文件清理。无需修改浏览器或全局配置。
