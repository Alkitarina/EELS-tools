# EELS 主成分分析模式使用说明

适用于 EELS Python Analysis 网页版的“纯 PCA 峰分析”模式

更新日期：2026 年 9 月 22 日

这份说明帮助你完成一件事：在 Si、Ge 或界面区域内，得到一条 PCA 重建谱，读取可分辨峰的位置与宽度，并检查这些数值在重复抽样时是否稳定。你不需要先学习矩阵运算，按下面的步骤即可开始。

当前模式的处理顺序是：选择区域和能量范围，进行 PCA 重建，识别峰，最后按需计算不确定度。它测量的是重建谱上已经形成的峰；几个重叠信号若只表现为一个宽峰，程序不能保证把它们拆开。

## 1 先用这组设置跑一遍

### 启动网页

在项目目录的 PowerShell 中运行 `./start_web.ps1`，后台服务就绪后会自动打开浏览器，随后可以关闭终端。同端口、相同代码的已有服务会保留当前数据并复用；新建服务先打开空白 UI，不读取上次数据或旧默认 H5，也不弹出文件选择窗口。进入页面后点击“导入数据”或“导入流程 JSON”。无浏览器或非交互启动同样不需要文件，仅显式传入 `-DataFile` 时才在启动时加载指定 H5。最新版地址固定为 [http://127.0.0.1:8768](http://127.0.0.1:8768)，端口被占用时明确提示，不会自动顺延。旧版服务需先导出结果，再用 `./stop_web.ps1 -Port 8768` 停止并重新启动。

项目文件夹：

仓库内的 `EELS_Python_Analysis` 文件夹。

需要换数据时可在网页中导入；若希望保留原会话，可用 `-DataFile` 指定另一份 H5，在其他可用端口新建服务。每次都要核对网页右上角的文件名。

## 2 每个参数该怎么理解

### 空间区域和能量范围

“Si”“界面”“Ge”是三个选框的名称，程序不会自动判断材料成分。先点击区域名称，再在信号图上拖出矩形。Si、Ge 选框应尽量位于各自材料内部；界面选框应围绕你希望研究的过渡区域。起始选框只是程序预设的位置，需要自己核对。

选框中的每个位置都有一条谱，程序会把这些谱取平均。选框越大，平均谱通常越稳定，但也更容易混合不同位置的特征。比较三个区域时，要考虑选框大小和位置是否合理。

能量范围同时控制信号图的积分范围和 PCA 分析范围。范围应包含目标峰以及两边足够的曲线，避免正好在峰顶或峰侧截断。窗口贴近零能量时，要检查零损失峰残余是否影响目标信号。

### 主成分数

可以把一个主成分理解为“整张谱像中一种常见的谱形变化方式”。保留 5 个主成分，就是用前 5 种变化方式重建曲线。**主成分数与峰数没有一一对应关系**：5 个主成分可以重建出 2 个峰，也可以出现更多峰。

主成分数太少，弱峰或局部细节可能被压掉；太多，噪声也可能保留下来。建议固定其他设置，依次试 3、5、8，比较峰位和宽度是否稳定。这只是人工对比办法，当前程序不会自动挑选最佳主成分数。

页面允许输入 1–64 的整数；实际可用上限还受数据数量和能量通道数限制。如果报“主成分数过大”，先降低数值。

### 目标峰数

它表示“最多保留几个满足条件的峰”。如果设为 3，但只找到 2 个合格峰，结果就显示 2 个，并提示其余峰未分辨。找到的候选峰太多时，程序优先保留突出度较大的峰，再按能量从小到大编号。

可输入 1–16 的整数。调大它不会创造新峰，也不会强制把一个宽峰拆成几个峰。

### 最小峰距

它是相邻候选峰之间允许的最小能量间隔，单位为 meV，必须大于 0。设为 5 时，距离太近的候选峰会被筛除。程序按实际能量通道间距换算，因此实际限制会有一个通道量级的取整差别。

如果曲线上出现许多密集的小峰，可适当增大；如果两个清楚的峰靠得很近，可适当减小。不要把它误当成峰宽。

### 最小突出度

“突出度”描述一个峰比它周围的参考基底高出多少。通俗地说，它看的是这个峰是否明显地凸出来，而不是只看峰顶数值大不大。参考基底由峰两侧的曲线决定。[突出度定义](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.peak_prominences.html)

页面中的百分比以**当前 ROI 在所选能量范围内的 PCA 重建谱最高值减最低值**为基准。例如这个差值为 10000，填 0.5% 就表示突出度至少为 50。输入范围是大于等于 0%、小于 100%。

小起伏太多时可从 0.5% 提高到 1%；弱峰被忽略时可尝试 0.2%。这些是对比用的试值。改变 ROI 或能量范围后，即使百分比不变，实际筛选门槛也可能变化。

## 3 程序实际做了什么

### 第一步 读取许多位置上的谱

数据里有两个空间方向 x、y，以及一个能量方向 E。数据尺寸记为 ny×nx×nE，共有 ny×nx 个空间位置，每个位置有 nE 个能量通道。选定能量范围后，程序只使用这段能量内的数据。

这里“原始谱”指载入 HDF5 文件中的数据。如果文件已经经过背景扣除或解卷积，页面中的原始谱也是处理后的谱，并不等于探测器最初采集的数据。

### 第二步 找到整张谱像的主要变化规律

程序先求整张谱像的平均谱，再观察每个位置相对于平均谱的差别，找出贡献较大的几种变化方式。这一步叫 PCA。它使用的是**当前文件中整张谱像的数据**，并非只用 Si、Ge 或界面的选框。

当前实现先减去平均值，再进行分解，没有把每个能量通道都强行缩放成相同大小。变化较强的能量段因而更容易影响结果。有关这一基本定义，可查阅 [PCA 官方说明](https://scikit-learn.org/stable/modules/generated/sklearn.decomposition.PCA.html)；本程序的实际计算流程以项目代码为准。

### 第三步 重建选区的平均谱

程序把选框内的谱取平均，用刚才保留的 K 个主成分重新表达这条平均谱，再加回整体平均谱。希望保留的是真实的共同变化，舍去一部分细碎波动，但弱信号也可能被舍去，因此要对照原始曲线检查。

单个主成分并不直接等于“Si 峰”或“Ge 峰”。材料归属仍要结合空间位置和实验背景判断。由于三个区域共用整张谱像的 PCA 基础，改变 Si 选框不会让 PCA 只学习 Si。

### 第四步 在重建谱上找峰

程序先寻找局部最高点，再按最小峰距和突出度筛选，最多保留“目标峰数”个峰。随后利用峰顶及左右相邻的两个数据点，画一条短的抛物线来细化峰位。这样得到的峰位可以落在两个能量通道之间。

这里的细化只涉及峰顶附近三个点。它不会提高仪器本身的能量分辨能力，也不等于用高斯曲线拟合了整个峰。

### 第五步 测量宽度并给出检查指标

程序在“从峰顶向下走半个突出度”的高度上，找到左右交点，两点之间的能量差就是半突出度宽度。它不一定等于高斯模型的 FWHM，尤其在峰重叠或背景倾斜时。[宽度定义](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.peak_widths.html)

页面还会显示两个指标：

- **保留方差比例**：保留的主成分解释了整张谱像中多少比例的变化。它不是峰位的准确率，99.69% 不表示峰位有 99.69% 的可信度。
- **重建 RMSE**：重建谱与选区原始平均谱之间的整体差距，单位跟强度相同。越小表示两条曲线越接近，但过度保留噪声也会让它变小。

如果选框恰好覆盖整张谱像，而且数据都有效，选区平均谱就是 PCA 的整体平均谱。此时重建 RMSE 可能接近零，即使主成分数很少也是如此，不能据此判断降噪效果特别好。

## 4 从选区到导出的完整操作

### 第一步 核对文件和模式

启动网页，检查右上角文件名。需要切换文件时，点击“导入数据”，选择 MAT/HDF5 或填写本地绝对路径。Toolbox MAT 文件会通过本机 MATLAB 后台转换，转换成功后自动加载；不会再做一遍解卷积。然后在“分析方式”中选择“纯 PCA 峰分析”。页面上方是信号图与选区平均谱，下方是参数区和峰参数表。

### 第二步 设置能量范围

填写起始与终止能量，点击“更新信号图”。程序会刷新这个范围内的积分图和平均谱。起始值必须小于终止值，范围内也要有足够的实际数据通道。

输入 10–80 meV 后，实际曲线可能从 10.3 到 79.8 meV。原因是程序只选取落在范围内的已有能量通道，通常无需为这点差别调整标定。

### 第三步 分别设置三个空间选框

点击“Si”选中对应选框，拖动边线或八个白色手柄调整大小，拖动框内可移动整个选框；在框外拖动可重新画框。然后切换到“Ge”和“界面”，分别调整。按 Esc 可取消当前拖动，单击不会清空原有结果。每次完成调整并松开鼠标后，程序会预览当前选区的原始平均谱；拖动过程中不会重新分析。用信号图标题旁的 x、y 范围检查选框是否正确，空间单位为 nm。

信号图采用类似 MATLAB Parula 的蓝—青—绿—黄色配色，按真实空间比例显示，不叠加网格。色条对应当前积分图的最小值到最大值；这里只改变显示方式，不改变积分能量范围或分析数据。

一个选框至少应包含两个有效位置上的谱。分析纯材料区域时，尽量避开界面；分析界面时，注意矩形过宽会同时混入两侧材料。

### 第四步 先做一次 PCA 分析

填写主成分数、目标峰数、最小峰距和最小突出度。点击“分析当前区域”只分析当前选框；点击“分析全部区域”会依次分析 Si、界面和 Ge，使用当时同一组参数。

如果希望不同区域使用不同参数，应逐个切换区域、设置参数、分析并记录。页面输入框不会自动恢复每个区域上次使用的参数，因此切换区域后要再次核对。

### 第五步 对照曲线检查峰

同时查看“原始”和“PCA”曲线，检查重建后是否保留了主要峰形。点击对应图例可以显示或隐藏曲线。PCA 模式下“拟合”和“背景”按钮不可用属于正常情况。

查看峰参数表。若设定 3 个峰却只得到 2 个，先看曲线上是否真的存在第三个独立峰顶，再考虑调整阈值。不要只为了凑齐峰数不断放宽条件。

### 第六步 比较参数并计算不确定度

固定选框和能量范围，先比较几种主成分数；有必要时再逐项调整峰距或突出度。每次只改一项，便于判断哪个设置改变了结果。修改参数后需要再次点击分析，旧图不会自动变成新参数下的结果。

确定一组合理设置后，填写重采样次数和空间块边长，点击“评估当前不确定度”。要同时评估三个区域，可使用“评估全部不确定度”；它会按输入框中的当前参数重新计算三个区域。

### 第七步 保存

计算完成后，点击“导出结果（JSON）”。单个文件保存峰参数、不确定度，以及各区域实际使用的选框、能量范围、分析参数、随机种子和数据校验信息，不再复制输入数据或逐次抽样明细。复现时需保留同一份输入数据和对应程序版本。改变选框或点击按钮应用新能量范围后，需要重新分析；刷新网页也会重置页面状态。需要保留的结果应先导出，不要把网页作为长期保存位置。

## 5 不确定度怎样计算

### 两个需要填写的参数

**重采样次数**是把分析重复多少遍，页面默认 500，程序接受 2–5000 次。希望区间更稳定时，可以在参数确定后比较 500 次或 1000 次。次数更多主要是让抽样区间稳定，并不能自动消除偏差或提升仪器精度。

**并行任务数**默认选“自动”。PCA 使用 CPU 多线程同时计算不同抽样，每个任务的矩阵库使用一个线程，避免线程之间争抢资源。任务数可手动调整，但不是越大越快；数据较大或电脑还在运行其他程序时，可以减小。抽样次数、峰数、能量窗口和拟合精度不会因为并行而减少。网页会显示实际使用的线程数。

每次抽样的随机数由已记录的种子和抽样序号决定，不由哪个线程先完成决定。改变并行数量不改变抽样序列；导出的 JSON 同时记录随机数规则和执行信息。旧版结果仍按旧版串行规则读取，不会被当成新规则。

**空间块边长**以像素为单位。填 1，按单个像素抽取；填 2，通常每次抽一块 2×2 的相邻像素；填 3，则是 3×3。因为相邻位置的信号可能相似，按块抽取能够保留块内的空间关系。默认值为 2。

建议先用 2，再与 1 或 3 比较。块并不是越大越好：如果选框只有 2×2 像素，块也设为 2×2，每次就只能抽到同一整块，区间可能很窄却缺乏判断意义。块大于某个空间方向时，程序会在该方向按可用尺寸截短。

### 每次重复会发生什么

1. 从整张谱像中随机抽取许多小空间块，允许同一个块被重复抽到，凑成与原来相近数量的谱。
2. 从当前选框中另外抽取空间块，得到另一份选区数据。
3. 用重采样后的整张谱像重新做 PCA。为加快重复计算，这一步采用 PCA 的近似加速算法。
4. 重建本次选区的平均谱，再识别峰和测量宽度。
5. 按峰位接近程度，把本次的峰对应到原结果的峰，记录峰位和宽度。若无法找到足够的峰或计算出错，这次记为失败。

这里采用的是**空间块重采样**。你之前提出的“拟合后按残差生成随机信号，再重复拟合”属于另一条思路；当前 PCA 模式没有按那种方式生成残差噪声。

### 怎样理解 95% 区间

所有成功重复得到的峰位按大小排列，程序取第 2.5% 和第 97.5% 的位置作为区间两端；宽度也按同样办法计算。它可以直观地描述：在当前选区、参数和抽样方式下，重复计算时这个数值会波动多大。

例如，“峰位 36.3 meV，95% 区间 35.9–36.7 meV”表示本次方法得到的区间估计为 35.9–36.7 meV。这个例子仅用于说明读法，不能把区间半宽 0.4 meV 直接叫作标准差。

### 判断结果时还要看什么

页面会给出成功次数，例如 180/200。区间只根据成功的重复计算，失败的 20 次不参与。失败较多时，区间可能只反映容易找回峰的那些情况，应先检查峰识别是否稳定。

成功匹配也不等于确定找回了同一个物理峰。当前程序主要根据峰位接近程度对应峰，没有为“最多允许移动多少 meV”设置单独的硬限制。强烈重叠或峰消失时，需要对照曲线判断。

这个区间反映了空间抽样、区域内部差异以及重新计算 PCA 带来的变化；它不包含能量标定、背景扣除、解卷积设置等全部误差。主成分数和选框位置对结果的影响，需要通过另做参数对比来检查。

## 6 结果怎么看和常见问题

### 峰参数表

| 字段 | 含义 | 阅读时注意 |
| --- | --- | --- |
| 区域 | Si、界面或 Ge 选框 | 是你指定的区域名称 |
| 峰 | 按能量升序编号 | 不同区域的峰 1 未必是同一物理模式 |
| 中心 | 细化后的峰顶能量 | 单位 meV |
| 峰位 95% 区间 | 重采样得到的峰位区间 | 没有计算时显示 -- |
| 半突出度宽度 | 指定高度上左右交点的间隔 | 不直接当成高斯 FWHM |
| 宽度 95% 区间 | 重采样得到的宽度区间 | 只描述当前宽度定义 |
| 突出度 | 峰高出参考基底的强度 | 与强度同单位，不是峰面积 |

### 峰数不够怎么办

先确认目标峰确实在能量窗口内，而且曲线上有独立峰顶。然后一次只尝试一个调整：适当降低突出度、减小最小峰距，或比较不同主成分数。如果目标信号只是宽峰上的肩部，纯 PCA 峰识别可能一直只返回一个峰。

### 峰很多而且位置不稳定怎么办

检查是否把噪声当成了峰。可适当提高突出度或峰距，比较较少的主成分。也可以在材料确实均匀的前提下扩大选框。不要同时改多个参数，否则很难知道结果为什么变化。

### 为什么宽度特别大

半突出度宽度是在整条重建曲线上量出的距离。邻近峰连在一起时，水平测宽线可能覆盖很宽的范围。先看图上的测宽横线跨过了哪里，再检查能量窗口和背景。不能只凭宽度大，就断定解卷积失败或某个独立振动峰真的这么宽。

### 为什么保留方差很高却找不到弱峰

保留方差统计的是整体变化。强峰可能贡献了绝大部分变化，一个弱峰即使很重要，对总体比例的贡献也可能很小。应查看弱峰所在能量段，而不是只追求 99% 或更高的比例。

### 为什么 RMSE 越来越小却不一定更好

增加主成分通常会让重建谱更接近原始谱，同时也可能恢复噪声。选参数时应综合比较峰形、峰位和宽度是否稳定。RMSE 的绝对大小还受强度尺度影响，不适合直接拿不同归一化方式的数据比较。

### 为什么重复点击得到几乎相同的区间

当前程序默认使用固定的随机种子，使同一设置的重复运行便于复现。重复点击并不等于获得了新的实验测量。要检查结果对选择的敏感程度，应有计划地比较选框、主成分数、能量范围或空间块大小。

## 7 保存与记录一次分析

### 下载的 JSON 包含什么

“导出结果（JSON）”保存当前页面仍保留的各区域 PCA 和高斯结果。`results` 中每个区域的 `peaks` 包含峰位、宽度、自助样本标准差与 95% 区间，Python 可以直接读取。PCA 和高斯宽度在 `width_kind` 中明确区分。尚未计算的不确定度为 `null`，不表示零。

即使一个峰也没有检出，也会保留该区域记录并令 `peaks` 为空数组。文件末尾 `reproducibility` 保存输入数据路径和数值校验值、程序版本、各区域的实际运行参数与 seed。每次抽样结果可以重新计算，不必逐个存下来；复现仍需保留输入数据和对应版本程序。JSON 不包含数据、谱线、源码或抽样明细副本。

各区域可以使用不同参数，导出会分别记录计算当时的参数，而不是导出时输入框的内容。每个模式、每个区域仅保留最近一次结果；被重新选框或更新能量图后清除的结果不会混入 JSON。比较多套方案时应分别导出。复现针对导入数据之后的分析，不包含此前仪器采集和 MATLAB 预处理。详细步骤见同目录的《数据导入与结果导出.md》。

### 建议保存的实验记录

| 记录内容 | 示例 |
| --- | --- |
| 数据文件 | sample.h5 |
| 数据处理阶段 | 按实际填写，例如已解卷积 |
| 分析区域与选框 | Si；记录 x、y 的最小与最大值 |
| 能量范围 | 10–80 meV |
| PCA 与峰识别设置 | K=5；目标峰数 3；峰距 5 meV；突出度 0.5% |
| 不确定度设置 | 200 次；空间块边长 2 px |
| 有效结果 | 记录检测到的峰数、峰位、宽度和 95% 区间 |
| 重采样成功情况 | 按页面填写，例如 198/200 |
| 参数对比 | 记录 K=3、5、8 时是否出现明显变化 |

表中的 198/200 仅为填写示例，不代表当前文件的计算结果。

### 怎样写结果描述

可以使用下面的句式，并用实际数值替换方括号中的内容：

“对 [文件名] 的 [区域] 平均谱，在 [起始–终止] meV 内进行 PCA 重建，保留 [K] 个主成分。以最小峰距 [数值] meV 和最小突出度 [数值]% 识别出 [数量] 个峰。所报告宽度为半突出度宽度。使用边长 [数值] 像素的空间块进行 [次数] 次重采样，其中 [次数] 次成功；峰位及宽度区间采用成功结果的 2.5%–97.5% 百分位数。”

比较 Si、Ge 和界面时，还应说明它们是否使用相同能量窗口与参数。若设置不同，就把差别写出来。不要仅按“峰 1、峰 2”编号认定不同区域的峰相互对应。
