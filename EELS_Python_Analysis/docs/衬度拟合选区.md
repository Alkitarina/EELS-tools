# 衬度拟合选区

左侧图像下方新增 **启用衬度拟合选区**，默认关闭。原有手工选框方式保持可用。

1. 勾选启用，选择拟合参考。默认使用 MAT 保留的 EELS 总计数；也可以选择已经加载的 Si/Ge 参考谱贡献图。两者均不等同于 HAADF。
2. 设置 Si、Ge 体区达到平台的比例，以及界面左右边界的 C 百分比。
3. 点击 **拟合预览**。一次计算 erf 和 logistic，展示一维衬度、拟合曲线、中心、10–90% 过渡宽度、原强度单位 RMSE 和 R²。
4. 在“应用模型”中切换模型比较；选择不会立即改变选框。修改比例或拟合参考后，需要重新拟合预览。
5. 点击 **应用到选框**。默认三个选框纵向取满；取消“应用时纵向取满”则保留各自原有 y 范围。应用后仍可拖动、缩放和重新绘制选框。

## 边界含义

程序按 Si 在左、Ge 在右计算。将拟合的平台归一化为 C=(I-I_Si)/(I_Ge-I_Si)，即使亮度从左向右降低，C 也从 0 走向 1。

| 区域 | 默认条件 | 横向范围 |
| --- | --- | --- |
| Si 体区 | 达到 Si 平台 99%，C≤1% | 图像左端到 x1 |
| 界面 | C 在 10%–90% 之间 | x10 到 x90 |
| Ge 体区 | 达到 Ge 平台 99%，C≥99% | x99 到图像右端 |

1%–10% 与 90%–99% 的间隔不属于这三个默认分析区域。百分比是衬度条件，不是化学组分。输入必须满足 Si 截止≤界面左界<50%<界面右界≤Ge 起点；100% 是渐近平台，不能作为有限坐标边界。

erf 使用 C=Φ((x-x0)/σ)，其中 Φ 为标准正态累积分布，xp=x0+σΦ⁻¹(p)，10–90% 宽度约为 2.5631σ。logistic 使用 C=1/(1+exp(-(x-x0)/s))，xp=x0+s·ln(p/(1-p))，10–90% 宽度约为 4.3944s。

沿全 y 平均不使用当前选框。中心和宽度属于当前参考信号的衬度过渡参数；不能直接解释为互扩散厚度或声子模式的空间范围。

## 失败、取消与数据保持

- 平台不清晰、有效列不足、优化失败时会提示原因。
- 若指定百分比落在图像之外或任一区域没有覆盖像素，仍可查看拟合，但不能应用这套区域；调整百分比或手动选区即可。程序不会强行生成一个“99% 体区”。
- 后端拟合进程最多运行 8 秒，超时会终止并回收；前端最多等待 12 秒后恢复按钮。取消会立即停止等待，迟到的结果不会应用；后台进程仍受硬超时限制。
- 关闭功能、切换模型或底图、修改边界、失败、超时和取消均不改选框。只有应用成功才清除坐标发生变化的区域的旧峰结果与预览。
- 新数据不会沿用旧拟合结果。峰结果 JSON 仍记录实际分析时使用的 ROI，包括应用拟合之后的手动调整。

使用 `start_web.ps1` 启动新版；旧会话会留在原端口，新版服务使用后续可用端口，避免丢失已有分析。
