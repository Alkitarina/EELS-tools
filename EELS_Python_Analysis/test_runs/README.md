# 测试产物目录

测试源码保留在 `tests/`；测试数据、截图、日志、任务备份和临时脚本统一写入本目录下的 `.tmp_<任务名>_<唯一后缀>/`。
目录名使用 `.tmp_` 前缀，表示完成验证、确认不再需要后可以删除整个目录。
不要把临时文件直接堆在项目根目录，也不要把真实 MAT/H5、正式结果或参数记忆移入这里。

每次任务结束，清理该任务已无用的临时产物；需要保留的验证证据仍集中在本目录并保留 `.tmp_` 标记。
删除前检查绝对路径属于本项目的 `test_runs`，且没有测试进程占用；只删除明确属于该任务的目录。
清理失败时停止，不扩大删除范围。

正式服务日志、启动记录、`ui_preferences.json` 和结果归档放在 `web_runs/`。
服务及复现任务的临时工作目录使用 `web_runs/.tmp_*/`，任务结束自动清理。
不要在计算尚未结束时删除它们。
