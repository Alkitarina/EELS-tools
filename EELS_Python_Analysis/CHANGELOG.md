# 更新记录

## 1.1.0 — 2026-10-13

- 增加“打开分析界面.vbs”双击入口：无数据参数启动空白网页，进入后再导入 H5、MAT、EELS-ZEST ZIP 或流程 JSON。
- 支持新版 EELS-ZEST ZIP 的原始 EELS 总计数：读取 `counts_source_totint` / `count_info.source_totint`，交叉校验重复记录，并保留到导入生成的 H5。
- 总计数可用于参考底图、普通分析及多变量工作流中的衬度拟合选区；选择去零损失峰后的信号谱或校正能量轴时，总计数保持不变。
- 保留缺失像素并同步处理空间坐标翻转；旧 ZIP 继续兼容。拟合能窗内的谱线求和不会替代原始 `EELS.info.totint`。
- 数据概览显示原始总计数是否可用。已有转换 H5 不自动补入新字段，需要重新导入新版 ZIP。

## 1.0.0 — 2026-10-13

- 采用 EELS-ZEST Parallel 的浅色渐变、半透明卡片和蓝色按钮样式；统一导入窗口、参数栏、数据概览及工作流步骤，适配窄屏。
- 支持直接导入 EELS-ZEST 结果 ZIP，读取空间标定、像素位置、谱线和能量轴；保留有符号信号及导入来源。
- 提供 PCA、高斯自动/手动分析，以及 NMF / MCR-ALS 界面残差工作流，包含四区选区、条带体谱、残差与联合分峰。
- 支持导入流程 JSON，恢复已保存的选区、参数和峰结果；将可编辑参数记忆在本机。
- 启动默认进入空白界面，日常入口固定为 `http://127.0.0.1:8768`，通过服务身份检查保护已有会话。
- 在界面和服务接口公开应用版本号。应用版本与既有科学结果格式版本独立。
